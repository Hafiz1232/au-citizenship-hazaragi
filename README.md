# Australian Citizenship Practice Tests (English text, Hazaragi audio)

Live site: https://hafiz1232.github.io/au-citizenship-hazaragi/

- 10 practice tests × 20 multiple-choice questions (A/B/C) = 200 questions. Every test has 5 Australian values questions.
- Pass rule (same as the real test): at least 15/20 (75%) **and** all 5 values questions correct.
- All on-screen text is English. Each question has a 🔊 button that reads the question and options in Hazaragi, and after answering a second 🔊 button reads the correct answer in Hazaragi (400 MP3 clips in `audio/`).

## Sources
- **Test 1** = the 20 questions of the official Department of Home Affairs online practice test
  (https://citizenshippracticetest.homeaffairs.gov.au/), copied word for word with the official answers. Marked "Official practice question".
- **Tests 2–10** (180 questions) were written from facts in the testable section of the official booklet
  *Australian Citizenship: Our Common Bond* (https://immi.homeaffairs.gov.au/citizenship-subsite/files/our-common-bond-testable.pdf, 2024 edition),
  in the style of the official questions. Every answer was checked against the booklet. The booklet itself has no sample questions.
- The real citizenship test question bank is not public.

## Audio
Hazaragi script (Perso-Arabic, Hazaragi wording such as استه، ره، د، مو، کُدم، مِیتنه) voiced with Microsoft Edge neural TTS `fa-IR-DilaraNeural` at −15% rate.
No Hazaragi TTS voice exists, so the accent is Iranian Persian.
